# Ватсу в Варварке — лендинг

Страница услуги «Ватсу» для Варварка СПА (Нижний Новгород, ул. Барминская, 15).

- `index.html` — вся страница: стили и скрипты внутри.
- `media/` — видео воды (бесшовные петли 9 с, 1600 и 960 px по ширине) и кадры-постеры.
- `img/logo.png` — логотип салона.

На сайт салона (Битрикс) переносится как отдельная страница: скопировать `index.html`, `media/` и `img/`.
Шрифт заголовков на сайте салона — Academy; в превью вместо него Cormorant Garamond.
Форма заявки пока демо, её нужно подключить к CRM салона.
